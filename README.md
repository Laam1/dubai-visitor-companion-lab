# Dubai Visitor Companion Lab

A practical project for building a small, source-grounded Dubai visitor-planning agent while studying Claude Code and preparing for CCAR-F.

## Start here

1. Read [GOAL.md](GOAL.md) for the product goal, boundaries, and success measures.
2. Read [research/market-evidence.md](research/market-evidence.md) for sourced context and the validation plan.
3. Work through [ASSIGNMENT.md](ASSIGNMENT.md) in order. Each step includes a build task and an independent check.
4. Reconcile [exam/coverage.md](exam/coverage.md) with the current official CCAR-F guide before claiming full exam coverage.

The initial product is a demo, not an official Dubai service. It must not book, pay, submit forms, or claim unverified facts. Market scale is documented; visitor pain and ROI remain hypotheses to validate.
